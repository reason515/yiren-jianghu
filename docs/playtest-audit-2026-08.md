# 1. 审计概要

**一句话总评**：气质已立、闭环未通——新玩家能被序章与村景留住，却在「先学武」历练门槛与首战磨血上断掉「再点一下」的理由。

九维均分 **3.4 / 5**。界面与文案已明显好于 2026-08-08 的 UI/UX V2 基线（DC-027 的 P0-1/2/3 均已修）；玩法上手仍被数值门槛与内容笔误卡住。

# 3. 对照表（yjh vs xkx Web vs pkuxkx）

读码锚点：pkuxkx `d/newbie_lxsz/weiminggu.c` + `newbie_village.h`（35 步）、`cmds/std/look.c` `go.c` `fight.c` `learn.c`；xkx2001 `web/app/src/components/MobileApp.tsx`、`CombatSheet`/`TrainSheet`/`ExitPad`、`newbie.spec.ts`；本项目 `onboarding.ts`、内容包青石村、`docs/sibling-borrowings.md`。

三类结论：**对齐且更好** / **对齐但手感仍差** / **有意裁掉后留下的空档**（35 步命令教学、命令行、实时相遇按 DC-003 不搬回）。

| 环节 | pkuxkx 命令行 | xkx2001 Web | 本项目试玩 | 结论 |
|---|---|---|---|---|
| 醒来 / 定位 | `look` 长描述 + 出口列表；weiminggu 强制 hp→吃喝 | EventLog + 场景卡；35 步脚本推着走 | 老屋长文 + 见闻 + 九宫格出口；GuideTip 四步 | **对齐且更好**（无命令、有序章） |
| 下一件事 | 35 步逐步解锁（葫芦→拜师→enable→杀虎） | 同 35 步 + UI 高亮 | 四步 GuideTip；乱序不倒退 | **对齐但手感仍差**：步数少是有意裁；「酒旗」与历练门槛让第一步说假话 |
| 学武 | `bai` + `learn xxx from`；0 级可学，精耗 ×2 | TrainSheet 当面请教 | TeachSheet 当面请教（DC-039）；**Lv0→1 需历练 ≥2**（`level²×2`） | **对齐但手感仍差**：GUI 对齐 xkx；门槛比 pkuxkx 首学更狠，且界面不解释 |
| 兵器 | 新手常有木剑/赠兵；enable 后招式名入战报 | 同 MUD 状态 | 学剑无剑，普攻「抬手」 | **有意裁掉后的空档**（未赠兵）变成教学空洞 |
| 首战 | 未明谷杀虎有血量/武器垫脚，一局可结束 | CombatSheet 着色 + 较短回合感 | 野狗 1v1；4+ 分钟未结束 | **对齐但手感仍差**：叙事结构对齐 xkx；时长远差于「教学展示」 |
| 战报结构 | `damage.c` / dodge 句；s_combatd 闲笔、race | 关键字着色 + EventLog | 一句一招闭环、兽动词、闲笔、着色（DC-050） | **对齐且更好**（人兽分流比命令行更干净） |
| 落败 / 回血 | `hp` 自查；eat/drink；heal_up 心跳 | 状态条 + 休息暗示 | 自然恢复已有（DC-051）；运功入口在顶栏；**战斗中逃跑/回气被显现锁、失败无指引** | **对齐但手感仍差** |
| 没银 / 打不过 | 村内零工、钓鱼等时间换银 | 较少强调 GUI 生计 | 村中杂役/垂钓（DC-042/043/045）；引导**不指向**打工 | **对齐且更好**（机制有）；**上手空档**（没人告诉你） |
| 出村 | 马车去扬州，脚本送到 | 同 | 官道→城门；本轮未自然走到 | 内容在（DC-018）；**首会话到不了**即上手问题 |
| 挂机回声 | 离线几乎无「你做过什么」 | 收益数字为主 | 生计叙事行 + 历练/潜能/银两 | **对齐且更好**（兑现「离线必须留下叙事回声」） |
| 命令密度 | look/go/fight/kill/score/hp/i/learn/bai… | Web 仍发 MUD 命令 | 结构化 UI，玩家不见指令（DC-003） | **对齐且更好**（有意裁掉命令行，空档用 Sheet 填了大半） |

## 4.1 🔴 P0 堵塞闭环（必须修）

| ID | 问题 | 证据 | 玩家后果 |
|---|---|---|---|
| P0-A | **引导「先学武」与历练门槛对撞** | GuideTip 步 2：「出门前，先到村北武馆……学一门傍身的本事。」TeachSheet 全部「历练不足」。`numeric-baseline`：exp 门槛 `level²×2`，0→1 需历练 ≥2；建角历练 0。在线杂役 `roundGain.exp=1`，约两圈才够 | 按引导走立刻碰壁；不知道可以先挂机打工。30 秒承诺失败 |

## 4.3 🟢 P2 打磨

- 生计战报 `reason`：「手动停止」（机制词，应改「你停了手头的活计」一类）。
- 四维分配「+」全禁用，无「先减后加」提示。
- GuideTip 在起程过场上就出现，抢叙事。
- 首战无可用绝招（疾风斩门槛远高于 Lv1），动作条只有空等自动普攻——可接受，但应在教学战里缩短等待。
- 见闻/战报「历时 N 时辰」对几分钟在线杂役略夸张（语义问题，非阻塞）。

# 5. 通过项（防下次重复审计）

以下与文档/承诺一致，**不要当新缺陷重开**：

1. **无命令行**（DC-003）：结构化 UI + API，玩家不见 look/go/fight。
2. **墨色行旅簿**：V2 P0-1/2/3 已修；token、自包字体、定制滚动条在生产生效。
3. **序章 / 登录 / 起程**：竖排卷轴、宣纸叩门、老屋晨光过场，沉浸明显好于 08-08。
4. **房间与 NPC 对话**：器物、留白、身份口吻符合 wuxia-copywriting；未抄金庸/古龙/黄易原句。
5. **战报结构**（DC-050 / combat-presentation）：一句一招闭环、关键字着色非整行、兽种动词（扑咬低吼）、击间闲笔、数值不进文案。
6. **生计离线回声**（DC-042/043）：叙事句 + 历练/潜能/银两；在线跑图见闻有「做过事」的感觉。
7. **自然恢复**（DC-051）：走动后气精可见回升；运功入口在顶栏（本轮战斗中未用成）。
8. **触控与组件语言**：44px chip、ChoiceRow、Sheet、二次确认体系仍在。
9. **切片范围**（DC-018）：四区五任务是既定边界；本审计不因「城/门派内容少」扣可玩性，只评现有村环是否好玩、好上手。
10. **不搬回 35 步命令教学**：空档用 GuideTip + 任务简报填，方向正确；问题在文案与门槛不同步，不是「步数不够」。
