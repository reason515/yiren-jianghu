# 2. 设计目标与体验承诺（V2）

V2 不推翻 V1 设计语言（墨色武侠、阅读优先、动作从世界长出），只解决一件事：**把已定的设计语言真正"画出来"**。

> **V2 体验承诺**：打开即江湖——首屏是墨底卷册而非白纸；30 秒内知道"我在哪、有何变化、下一步分量"；每一次点击都有明确的质感反馈；在任何一台设备上，字体与色调都一致。

验收判据（与 mobile-ui skill §6 清单合并执行）：

1. 主界面任何一屏无白底浅字、无默认系统滚动条；
2. 字体不再回退系统字体（`document.fonts.check('16px "ZCOOL XiaoWei"')` 为真）；
3. 所有可点元素 ≥44px 且具按压态（`:active` 视觉变化）；
4. 逐屏对照 §6 验收点通过，走查截图前后对比存档。

# 4. 信息架构 V2

保持 V1 骨架（场景常驻 + Sheet 浮层 + 无跳页），调整如下：

```text
顶栏（新增固定）：生存状态紧凑条（气/精/内力 + 低值警示）+ 银两 —— 点击进人物
  ↓
主内容：场景叙事（+ 场景名印章） → 见闻 Tab → 此刻可往 → 场景动作
  ↓
底部动作条：当前情境 2–3 件最值得做的事（战斗中为悬浮动作条）
  ↓
底部导航（收敛为 6 项）：角色 / 挂机 / 任务 / 论剑 / 论坛 / 更多
    └ 更多抽屉：榜单 / 地图 / 离开
```

- **顶栏状态条**：当前"生存资源只在人物簿展开"的决策保留（mobile-ui §2），但**常驻一条紧凑状态条**（气/精/内力 + 银两），减少进面板的次数；低值时色彩+文案双警示（沿用现有 Bar）。
- **导航收敛**（待确认项 #1）：高频操作（角色/挂机/任务/论剑/论坛）5 项 + 「更多」抽屉收纳低频项（榜单/地图/离开）；战局为情境性按钮，战斗中临时出现在导航位（现状保留）。理由：8 项平铺字号被压缩到 13px、无主次，违背移动端"一眼可达"；收敛后每项可回到 15–16px 并加图标。
- **场景氛围**：场景标题旁加首字印章（ArtPlaceholder 接入，呼应 DC-006 轻量插画）。

# 5. 视觉系统 V2

## 5.1 背景体系（P0-1 修复）

```css
html, body, #root, .app { background: var(--ink); color: var(--paper); }
```

- 全局墨底补全（根因修复）；正文色 `--paper`，次级 `--paper-dim`。
- **宣纸纹理层**：在墨底上加一层极低透明度的 SVG 噪点/纸纹 data-URI（约 2–4% 不透明度），打破"纯黑扁平"，不干扰阅读。
- **场景氛围层**（P2）：场景卡顶部场景名 + 首字印章 + 一条墨→墨绿的渐变氛围条（呼应 xkx 的墨色体系与 DC-006 插画边界——不建设 2D 场景，只做氛围）。
- 保持"细线分栏如简牍"：`--line`/`--line-strong` 边框体系不动。

## 5.2 字体自包（P0-2 修复）

- 目标字体：`--font-display: "ZCOOL XiaoWei"`（标题/主按钮）、`--font-body: "Noto Serif SC"`（正文）。
- **子集化自包**：取两字体 woff2 子集（GB2312 6763 常用字 + 全角标点 + Latin），放 `apps/h5-client/public/fonts/`；`tokens.css` 顶部加 `@font-face` + `font-display: swap`。
- 体积预算：单字体子集 ≤ 350KB woff2；构建产物总增量 ≤ 700KB（gzip 后更小）。
- 构建：本地一次性生成子集文件提交进仓库（vite 直接 public 拷贝），不引入运行时子集化依赖。
- 验收：`document.fonts.check()` 双字体为真；真机截图无系统字体回退。

## 5.3 组件质感体系（P1-1 修复）

统一"可点性"语言：任何可点元素 = 边框 + 底色分层 + 按压态。

| 元素 | 常态 | 按压态（:active） | 用途 |
|------|------|-------------------|------|
| `.chip.action` | 玉色 tint 底（jade 0.12）+ 玉色边框 + `--jade-bright` 字 | `transform: translateY(1px)` + 亮度提亮 | 正向动作（交谈/拾取/前往） |
| `.chip.danger` | 朱砂 tint 底 + 朱砂边框 | 同上 | 高风险（放弃/举报/战斗结束确认） |
| `.chip`（普通） | `--ink-lift` 底 + `--line-strong` 边 + `--paper` 字（对比度≥4.5） | 同上 | 次级/列表操作 |
| `.btn.primary` | 玉色实底 + 深色文字 + 轻投影 | 压暗 6% + 下沉 | 主 CTA（入门/确认/开始） |
| `.btn.danger` | 朱砂实底 | 同上 | 破坏性主 CTA |
| Sheet 关闭 × | 44×44 热区 + 常态 `--paper-dim` | 提亮 | 全局浮层关闭（P1-5 修复） |

- 全部基于现有 token，不新增写死色值；新增投影/缓动用新 token（§7）。

## 5.4 滚动条与表单（P0-3 / P1-3 修复）

```css
::-webkit-scrollbar { width: 8px; }
::-webkit-scrollbar-thumb { background: var(--line-strong); border-radius: 4px; }
::-webkit-scrollbar-track { background: transparent; }
html { scrollbar-width: thin; scrollbar-color: var(--line-strong) transparent; }
```

- 全局细墨滚动条；登录页/场景页 `overflow: hidden`（无内容滚动需求处）。
- 输入框：常态 `--line-strong` → focus 玉色边框 + 微光晕；按钮与输入框间距恢复呼吸（`gap` 12→16px）。

## 5.5 动效基线（P2）

只动 `transform/opacity`，不动布局属性：

- Sheet 上滑入场 200ms ease-out（借鉴 xkx）；页面淡入 120ms；按钮按压 60ms；
- 状态条宽度变化 300ms ease；toast 沿用现有 200ms；
- 绝招高亮维持"一条高亮文本"（已定决策，不加粒子特效）。

- 现状（V2.15 前）：单卷长列表；资源行偏暗；行止无上限；武功三钮常显。

## 6.6 地图（MapSheet）

## 6.7 论坛

## 6.8 榜单 / 论剑

## 6.9 建角流程（CharacterCreateSheet，V2.3）

- 现状（V2 前）：Sheet 浮层内一屏塞满（名号/性别/四维/按钮），无故事背景、无引导。

# 7. 工程化落地清单

## 7.1 新增 token（tokens.css）

```css
/* 投影与缓动（V2 新增） */
--shadow-btn: 0 2px 8px rgba(0, 0, 0, 0.35);
--ease-out: cubic-bezier(0.22, 1, 0.36, 1);
/* 纹理与氛围（可选，data-URI 内联，不新增色值） */
```
