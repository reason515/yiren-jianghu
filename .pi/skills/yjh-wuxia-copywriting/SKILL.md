# 《一人江湖》武侠文案规范

## 定位

游戏是"文字叙事为主"的移动端武侠 RPG——文案本身就是核心玩法。目标是让玩家在读绝招、场景、对话时产生**读武侠小说的代入感与爽快感**，而不是看说明书。

**原创红线**：借鉴神韵，绝不抄录金庸/古龙/黄易等原句（版权与项目原创要求）。可以引用其"句式气质"，不可搬运其"具体句子"。

## 三家风格内核（各自取什么）

| 风格 | 取什么                                                             | 不取什么                 |
| ---- | ------------------------------------------------------------------ | ------------------------ |
| 金庸 | 招式的来历与画面、动作连贯、武学与心境呼应（"力由脊发""意在剑先"） | 长篇铺陈、过度写实考据   |
| 古龙 | 短句、留白、杀机氛围、不写过程写结果（"没有人看清那一剑"）         | 句句断行到零碎、过度悬疑 |
| 黄易 | 境界气象、气机牵引、天人合一、大场面（"剑气纵横"）                 | 玄学堆砌、故弄玄虚       |

**融合原则**：以金庸的"招式画面感"为骨，古龙的"节奏与留白"为气，黄易的"境界感"为神。

## 爽快感五原则（每条文案都要过一遍）

1. **先声夺人**：起句给画面/声音/寒意，不让读者从"他使出一招……"开始。
2. **虚实相生**：关键动作点到为止，留白给读者想象（古龙式）；次要细节才铺陈（金庸式）。
3. **身心合一**：招式与内息、心境联动（"真气随剑走""心随意动"），让武学有道理。
4. **境界分级**：低阶招式朴素利落，高阶招式才有气象——不要新手绝招就"剑气纵横三万里"。
5. **节奏收束**：短句为主、四字顿挫；结尾一句收得干脆，或留一个画面。

## 绝招/招式描述模板（60–130 字，2–3 句）

```text
第 1 句  起势/氛围：风、光、声、寒意、内息的变化
第 2 句  发招：一个核心动词 + 一个清晰画面（虚实自选）
第 3 句  收束/留白：对手的反应、或一个余韵画面
```

**分级对照**（防止数值与文案不匹配）：

| 等级                  | 写法                 | 示例调性                           |
| --------------------- | -------------------- | ---------------------------------- |
| 低阶（入门招式）      | 朴素、利落、画面清晰 | "没有花哨，只一记快得看不清的平斩" |
| 中阶（登堂入室）      | 细节丰沛、五感齐备   | "剑势一起，如墨云压城"             |
| 高阶/绝学（开宗立派） | 气象、境界、天地联动 | "剑光过处，天地为之一静"           |

## 技法清单

- **动词要狠**：裂、破、斩、贯、崩、荡、噬、泼、压、卷。慎用"打""攻击""造成伤害"。
- **用五感**：风声、剑鸣、寒意、血腥气、皮肤发麻。
- **四字顿挫**：多用四字短语制造节奏（"浊气下沉，清气上升"）。
- **数字/对比造张力**："快得像从时间里剪去一截""退到无路可退"。
- **身位与空间**：写清距离与方位（"咽喉前三分""周身三寸"），让画面立起来。
- **对手的反应**：伤害类写对手的退/矮/僵；治疗类写身体的松/暖/沉。

## 红线（禁止）

- 现代词汇与网络用语（"眩晕""BUFF""拉满""主打"）。
- 说明文句式（"本招式造成 12 点伤害""附带冷却"）——数值永远不进文案。
- 形容词堆砌（"无比强大的绝世神功"）。
- 同质重复（同一批绝招都用"快如闪电"）。
- 直接或变相抄录既有武侠小说原句。
- 描述与数值/机制矛盾（低阶绝招不能吹成灭世）。

## 检查清单（写完后逐条自查）

1. 起句是否先给画面/氛围，而不是"他使出"？
2. 是否至少一处留白（没说透的部分）？
3. 动词是否具体、有力，避开了"攻击/造成"？
4. 是否贴合绝招的数值与阶位（低阶不吹大）？
5. 是否混入数值、现代词或说明文？
6. 读一遍，有没有"像在读武侠小说"的爽快感？没有就重写。

## 示例（before → after）

**示例 1：疾风斩（低阶）**

- 前："看似平凡的一剑，胜在快如疾风。"
- 后："剑未至，风先裂。没有花哨，只一记快得看不清的平斩——等风声落定，对手才觉出胸前一凉，低头时，衣襟已破。"

**示例 2：追风破（中高阶/处决）**

- 前："觑准敌手破绽，一剑如追风逐电，专破强弩之末。"
- 后："觑准破绽，一往无前。这一剑没有后招，也不留余地——追风逐电，只为在敌人心神最松的一瞬递出致命一击。出剑之后，风才追上。"

**示例 3：乾坤聚气（内功/治疗）**

- 前："运转玄门内功，浊气下沉、真气归元，伤势为之平复。"
- 后："浊气下沉，清气上升。丹田一点暖意化作溪流，沿经脉游走；伤处像被温水浸过，紧绷的筋骨一寸寸松开，呼吸渐沉，气机复圆。"

## 房间/场景描写模板（场景卡，60–150 字，2–3 句）

```text
环境（时令/光线/器物）+ 气息（气味/温度/声响）+ 一个动态细节（有人有物在动）
```

- 场景是玩家行动的舞台：写完要能看出“能碰什么、能去哪、此地何情”。
- 动态细节让场景活着：酒旗无风自动、算盘珠声、炊烟、阴影里的人。
- 不要写成说明文（“这里是村口广场，往南是客栈”）；把方位融进画面（“往南是村中客栈，屋脊上炊烟正起”）。

**示例**

- 前：村口广场。
- 后：晒谷场上稻香未散，青石被日头晒得发白。远处几声犬吠，拐角的酒旗无风自动，像在等人。

## NPC 对话模板

- **贴合身份**：守卫、商贩、师父、隐士各说各话；口语化，不书面，不文绉绉。
- **留白**：重要人物话少；交代任务时给足线索但不剧透。
- **场景调性**：交易干脆、拜师郑重、任务“一句情境 + 一句指向”。
- 多句对话放进内容包 `dialogue` 数组，按玩家状态/事件切换。

**示例（守卫）**

> 站住。村里这两日不太平——过路的交个路引，闲逛的趁早回去，天黑前城门要关。

## 任务简报模板（questSchema.briefing，40–100 字）

```text
一句情境（为什么有这个任务）+ 一句指向（做什么、在哪、得什么）
```

- 目标明确但不说破机制：不写“击杀 1 个守卫”，写“去会一会库房那些‘住户’”。
- 语气承接 NPC 身份与任务类型（悬赏/师门/主线各有调性）。

**示例（悬赏）**

> 近来库房总有些动静，米袋上尽是齿印。村长悬了赏：去库房清理那些“住户”——麻利些，别让它们再糟蹋口粮。

## 应用范围与落点

- **绝招描述**：`packages/content/**/performs/*.json` 的 `description` 字段。
- **战斗演出文本**：C3 战斗事件 → 前端演出的文案（E 阶段），遵循同规范（短句 + 动词 + 留白）。
- **房间/NPC/任务/剧情**：内容包对应文件；对话要"有人说人话"（贴合 NPC 身份）。
- 写完后跑 `pnpm content:validate`，确保内容包结构不被文案改动破坏。
